# 五目並べ 必勝トレーナー

15路・制限なし（三三・四四・長連すべて可、五連以上で勝ち）の五目並べ。
`index.html` をブラウザで開くだけで動きます（通信なし・インストール不要）。

## できること

- **対戦**：CPU は「普通／強い／最強」の3段階。先手・後手を選べます。
- **説明（必勝法）**：黒番で打ちながら、おすすめの手と理由（三・四・四三など）を表示。お手本手順の再生つき。
- **戦績**：強さ別の勝敗と最近50局をブラウザに保存。
- **振り返り**：対局後に1手ずつ読み直し、敗着・勝ち逃し・代わりの手・相手の勝ち筋を表示。

## 中身

| ファイル | 役割 |
| --- | --- |
| `index.html` | 配布物（下の3つを1枚にまとめたもの） |
| `src/engine.js` | 思考エンジン。四・三の連続攻めの詰み探索、先読み、定石 |
| `src/ui.js` | 画面と進行、戦績、振り返りの文章 |
| `src/page.html` | ページの枠とスタイル |
| `build.py` | `python3 build.py` で `index.html` を作り直す |
| `tools/solver.cpp` | 定石とお手本の検証に使った詰み探索（C++） |
| `tools/selfplay.js` | レベル同士の自己対戦（`node tools/selfplay.js 黒Lv 白Lv 局数 0`） |

## 強さと正しさについて

- 五目並べ（制限なし・15路）は先手必勝と証明済み（Allis ら, 1993）。ただし証明は巨大な分岐の木で、短い「公式」ではありません。
- このエンジンは完全解析ではありません。四・三の連続攻めは十数手先まで正確に読みますが、静かな手が何手も続く勝ち筋は読み切れないことがあります。
- 定石（黒5手目）とお手本は `tools/solver.cpp` で「白の応手を石の周囲2路以内すべて」調べて黒勝ちを確認したものだけを収録しています。
- 自己対戦では 最強 > 強い > 普通 の順に、先手・後手どちらでも勝ち越すことを確認しています。
